NEON BAY is a 2D top-down open-world crime game: play Jax Marlowe in the original neon city of Neon Bay — steal cars, run getaway missions, fight back, and outrun the police as your wanted level climbs from 1 to 5 stars, with roadblocks and a police helicopter at the top. Pure HTML5 canvas and vanilla JavaScript, no libraries, no network — it runs fully offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD to move, E to enter a car, F to punch, Space to shoot, P to pause, M to mute.
